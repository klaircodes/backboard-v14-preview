Start with R-CLI

An open-source coding agent for your terminal, on whichever model fits.

Four steps

  1. Create your account

    Free to start, no credit card required.

    Create your free account

  2. Install it

    macOS and Linux

    curl -fsSL https://app.backboard.io/api/cli | bash

    Windows (PowerShell)

    irm https://app.backboard.io/api/cli/windows | iex

  3. Sign in

    backboard login

    This opens a browser to connect the CLI to your account. To bring your own key instead, run /providers inside R-CLI.

  4. Open a project and ask

    cd your-project
    backboard

    Describe what you want. R-CLI inspects files, edits code, runs commands and checks its work, keeping changes reviewable through permissions and checkpoints.

The source is on GitHub, MIT licensed. More on the R-CLI page.
